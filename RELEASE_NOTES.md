# Release Notes

All notable changes to the skills in this repository are documented in this
file. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and every skill
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Versions are tracked per skill, so each release heading names the skill and its
version, for example `## [my-skill 1.2.0] - 2026-10-16`. Changes are grouped
under `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed` and `Security` as
described by Keep a Changelog.
