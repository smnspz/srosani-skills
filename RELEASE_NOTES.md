# Release Notes

Repository-level index of skill releases. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and every skill
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Each release heading names the skill and its version, for example
`## [my-skill 1.2.0] - 2026-10-16`. The authoritative, detailed changelog for
each skill lives in that skill's own `CHANGELOG.md`.
